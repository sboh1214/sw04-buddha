> **Buddha · 거래 중심 제품 기획**
> 가상 Coin으로 YES/NO 계약을 호가창에서 거래한다. 운영 마켓메이커가 초기 유동성을 보완한다. 별도 확률 입력은 없으며 스코어링은 미정이다.

### 제품의 기본 방향

사용자는 시장을 발견하고 규칙·가격·호가를 확인한 뒤 계약을 매수·매도한다. 중도 매도 또는 결과 정산을 통해 Coin 손익을 확인하고 다시 시장을 탐색한다.

주식 거래와 유사한 주문 경험을 제공하되 주식 자체가 아니라 결과에 따라 지급되는 사건 계약이다. YES/NO 선택은 거래 계약 선택이며 별도 투표가 아니다.

### 설계 상태와 출시 전 남은 작업

비점수 영역의 정책·화면 설계안 v0.2 작성 완료. 구현·운영 승인·시뮬레이션 완료를 뜻하지 않는다.

초기 지급액, 재지급 조건 수치, 봇 예산·최대 손실·b·호가 물량·가격 보호 폭은 함께 시뮬레이션해 확정한다. 손실 한도 70%/90% 단계는 테스트용 제안이다. 100 Coin 지급 단위, VOID 50/50, 24시간 이의 기간도 설계 제안으로 구분한다.

개인정보 보존기간·운영 담당·출시 설정은 배포 전 명시한다. 유료 판매와 스코어링 결정을 초기 거래 출시의 필수 의존성으로 두지 않는다.

### 이번 개정에서 바뀐 점

- Trade + 별도 Forecast의 Hybrid 구조를 계약 거래 한 가지 참여 흐름으로 변경.
- 직접 AMM 체결에서 CLOB + 운영 마켓메이커로 변경.
- 순위·점수·확률 집계의 기존 가정을 제거하고 미정 처리.
- Coin 거래 손실을 소각으로 보던 설명 수정.
- 유료 Coin 구매 계획을 삭제하지 않고 별도 후속 문서로 분리.
