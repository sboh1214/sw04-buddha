# 04 프로필과 활동 기록 · 스코어링 보류

설계안 v0.2 · 2026-10-04

### 1. 프로필의 역할

사용자의 소개와 공개 토론 활동을 연결한다. 거래 수익이나 코인 잔액을 예측 실력으로 단정하지 않는다. 별도 Forecast 입력·확률 이력은 제공하지 않는다.

### 2. 공개 프로필

닉네임, 이미지, 소개, 선택한 관심 카테고리, 가입일, 공개 글·댓글을 제공한다. 게시글과 댓글에서 프로필로, 프로필의 글에서 해당 시장으로 이동한다.

초기에는 잔액·주문·미정산 보유 수량·개별 체결·손익은 본인 전용이다. 계정 이메일·인증 정보·내부 위험 플래그를 노출하지 않는다. 글을 작성했다고 보유 방향을 자동 공개하지 않는다.

관리자 표시는 운영 권한만 의미하며 예측 실력 인증이 아니다. 봇은 일반 사람의 소개·활동으로 꾸미지 않으며 공개 사용자 수에서 제외한다.

### 3. 본인 활동 기록

MY에서 보유 계약, 주문·체결·정산 이력, 지갑, 내 글, 관심 시장을 확인한다. 기간·시장·거래 유형 필터와 상세 내역 연결을 제공한다.

손익은 거래 회계 정보이며 스코어가 아니다. 초기 지급·재지급·추가 지원은 거래 수익에서 제외한다. 계산법과 평가가격 기준은 02 거래와 화면 · Trading & Product UX를 따른다.

### 4. 스코어링·순위: 이번 범위 제외

평가 수식, 점수, 평판, 카테고리 등급, 종합·기간별 순위, 실력 배지, 대회 우승 산정은 미정이다. 현재 화면에는 임의의 점수·순위를 만들어 넣지 않고 관련 메뉴를 숨긴다.

별도 확률 입력이 없어졌으므로 이전 Brier/Log·시간 가중 Forecast 평가와 Community Forecast 집계안을 그대로 적용하지 않는다. 거래 가격이나 포지션을 사용자의 명시적 믿음 확률로 취급하지 않는다.

후속 설계 시 무엇을 평가할지와 데이터·자산 규모·시장 유동성·선택 편향을 검토한다. 본 문서는 평가 방식을 선택하지 않는다.

### 5. 향후 평가를 위한 사실 기록

주문·체결의 서버 시각, 계약 방향·가격·수량, 수수료, 입출처별 코인 지급, 시장 규칙 버전, 마감·판정 결과, 계정 유형을 보존한다. 아직 존재하지 않는 개인 확률을 추정해 기록하지 않는다.

### 6. 개인정보와 계정 관리

프로필 수정은 공개 항목에만 적용한다. 공개 글을 삭제하면 삭제 표시를 남겨 답글 문맥을 유지하고, 신고·감사 보존 데이터는 접근 권한을 제한한다. 계정 비활성화 후 공개 식별자를 익명화하되 거래 원장은 정산·운영 목적에 필요한 정책에 따라 보존한다.

보존기간·탈퇴 처리 일정은 출시 운영 설정에서 명시한다. 스코어 정책 미정이 프로필·MY 출시를 막지 않도록 분리한다.

### 7. 인수 조건

다른 사용자가 비공개 자산·주문을 조회할 수 없어야 한다. 프로필 수정·삭제·차단과 게시글 연결을 검증한다. 점수·순위·Forecast 입력이 화면과 알림에 남아 있지 않아야 한다.
