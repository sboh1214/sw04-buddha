# E2E 실행 구성

#129부터 전체 검증은 다음 세 구성을 **모두** 실행한다. 기본 3샤드 통과만으로 전체 E2E를 통과했다고 기록하지 않는다. 각 구성은 별도의 fresh Postgres 시험 DB와 Redis DB를 쓰며, API·web·worker 포트는 한 구성씩만 소유한다. 서버는 해당 구성의 DB/Redis 환경으로 시작해야 한다.

| 구성                | 명령 (저장소 루트)                                          | 단계 시험값: reduce / halt / ratio | 금고 준비                                                      |
| ------------------- | ----------------------------------------------------------- | ---------------------------------- | -------------------------------------------------------------- |
| 일반 회귀 3샤드     | `pnpm --filter web test:e2e --shard=1/3`, 이어 `2/3`, `3/3` | 0 / 0 / 0                          | 실제 두 관리자 승인으로 시험용 가용 재원 100,000,000 Coin 준비 |
| 실제 봇 호가, 두 폭 | `pnpm --filter web test:e2e:market-maker`                   | 7000 / 9000 / 5000                 | 같은 승인 절차로 시험용 재원 준비                              |
| 부족 금고, 두 폭    | `pnpm --filter web test:e2e:treasury`                       | 0 / 0 / 0                          | 선발행 없음; 해당 시험의 재원 보충만 실행                      |

- 각 구성은 375px·1280px를 모두 실행한다. 기본 config가 제외한 `@market-maker-quotes`·`@isolated-treasury`는 별도 config가 선택하며 `skip`한 시험이 아니다. CI와 전체 검사 runner도 세 구성을 모두 포함해야 한다.
- 0/0/0은 초기 보유가 없는 MM의 위험 증가 호가를 억제해 기존 사용자 주문 회귀의 빈 호가 전제를 유지하는 **시험값**이다. 봇 실행기·시장 검수·초기 배정을 우회하지 않는다. 7000/9000/5000도 실제 호가 시나리오의 명시적 시험값이며, 어느 값도 운영 기본값이나 출시 승인값이 아니다.
- 단계값이 이미 다르게 입력되어 있으면 global setup은 실패한다. 다른 프로필의 설정을 덮거나 기본값으로 추정하지 않는다. `marketMakerProfile` metadata는 두 전용 config에서만 정한다.
- 일반·실제 호가 프로필은 global setup에서만 부족한 시험 재원을 실제 발행 요청과 다른 관리자 승인으로 준비한다. 시장 helper는 금고를 자동 보충하지 않으며, 승인된 시장 A를 실제 배정해야 개장한다.
- 부족 금고 시나리오는 시장을 만들지 않는다. 다른 구성의 자동 개장·자금 배정·발행과 공유하면 실패 근거가 바뀌므로 전용 fresh DB/Redis에서 단독으로 실행한다. 두 viewport는 `workers: 1`로 순차 실행한다.
- local DB는 `5433`, `buddha_e2e_*` 등의 기존 fixture 허용 이름과 명시적인 app/owner URL이 필요하다. CI는 저장소의 disposable 서비스만 허용한다. 자격 증명을 로그·스크립트에 저장하지 않는다.
- `--list`는 서버·global setup·DB 연결 없이 각 구성의 시험 목록을 확인한다. 실 실행의 통과를 대신하지 않는다.

완료 보고에는 일반 3샤드 및 전용 두 구성의 passed / failed / flaky / skipped를 각각 기록하고 중복 없는 합계를 낸다.
